# Issue tracker: GitHub

Issues and specifications for this repository live in [GitHub Issues](https://github.com/intelligentrascal/skill-manager/issues).

## Conventions

- Create, read, comment on, label, and manage issues with `npx -y gh-axi`.
- Create a GitHub issue whenever an engineering skill says to publish work to the issue tracker.
- Read the issue and its comments before acting on a referenced ticket.
- Pull requests are not a triage request surface.

## Dependencies

Use GitHub's native issue dependencies where available. Otherwise, add a `Blocked by: #<number>` line to the issue body. A ticket is ready only when all of its blockers are closed.
